## 2026-05-27 - Interactive Element Accessibility
**Learning:** Interactive UI components within the application (e.g., links functioning as cards, icon-only buttons) sometimes lack critical accessibility attributes like `aria-label` and keyboard focus indicators.
**Action:** Ensure all newly developed or modified interactive UI elements are systematically reviewed for necessary accessible names, and explicit focus-visible states matching the design token guidelines (e.g., `focus-visible:ring-2` for Tailwind).
